# 🧮 Custom Calculation Overview

Custom Calculations refers to calculations performed on the output of the PK analysis step. The input file for this step is the output results file `pk-results.csv` and the output file for this step is always named `pk-results-custom-calcs.csv`. 

There are currently 2 custom calculations that can be performed. The Ratio tool will calculate the ratio of 2 parameters. This can be used to calculate things such as relative bioavailability, accumulation ratio, metabolic ratio, and dose normalization. The Conversion tool will perform an arithmetic conversion using a fixed value. This can be used to convert units for output parameters. Automatic unit conversion is not available; however, the user can determine the correct conversion factor and then apply it using the Conversion tool. 

Detailed explanations of these 2 tools can be found by using the links in the left side menu. Additional tools are being added all the time.
