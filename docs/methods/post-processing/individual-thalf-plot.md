Creates an individual concentration-time plot for a single profile with a logarithmic Y-axis. The observed data will have points and optionally a line that connects those points. The best-fit terminal slope will be represented by a line on the plot starting at the first time point used in the slope estimate and ending at the last time point used in the slope estimate. Additional lines for all estimated terminal slopes can be added if desired. Output includes an image file (png format) and a data file (csv format).
