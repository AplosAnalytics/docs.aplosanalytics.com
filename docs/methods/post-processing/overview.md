# 📊 Post Processing Overview

Post Processing refers to generating tables and figures from the input and output files from the PK analysis. The following files are available in both the table and plot tools:

 - original source data file (converted to CSV)
 - data file from data cleaning (if available)
 - `pk-results.csv` output from PK calculation step
 - `pk-results-custom-calcs.csv` output from custom calculation step (if available)
 
Users can create any combination of plots and/or tables to be created. Detailed explanations of each table or plot can be found by using the links in the left side menu. Additional tables and plots are being added all the time.
