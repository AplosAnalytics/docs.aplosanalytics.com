# 📄 Reports Overview

The Reports tool allows a user to incorporate tables and figures into a Microsoft Word document for use in a report. Any table or plot created in the post-processing step is available and can be added more than one time if desired. 

Each report can be divided into multiple "Sections". In the future, users will be able to modify settings for each section independently (e.g. page orientation). The section names are arbitrary and not included in the output file. 

All plots are included as images. Tables can be included as images or text. All plots and tables include footnotes with the source of the data as well as the time and date of creation.
